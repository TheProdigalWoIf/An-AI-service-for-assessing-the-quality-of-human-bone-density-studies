# DXA QC Lab

Локальный сервис контроля качества рентгеновских денситометрических снимков (DXA) по
техническому заданию Департамента здравоохранения: пакетное чтение DICOM, мультитаск-модель
ResNet18 (область → сторона → критерии качества), итоговое решение с причинами, CSV-отчёт
установленного формата и веб-интерфейс для проверки снимков.

Все вычисления выполняются локально, внешние сервисы не используются, GPU не требуется.

**Подробная документация** (архитектура, стек, развёртывание, API, обучение) — в файле
[DOCUMENTATION.md](DOCUMENTATION.md).

## Возможности

- Автоматическое определение анатомической области (`lumbar_spine` / `proximal_femur`)
  и стороны бедра (`right` / `left`).
- Оценка качества снимка по пяти экспертным критериям: укладка, ось позвоночника,
  артефакты, ротация/позиционирование бедра, корректность ROI.
- Итоговое решение «хороший / плохой» с перечнем нарушенных критериев и статусом
  `needs_review` при недостаточной уверенности.
- Веб-интерфейс проверки снимков и REST API.
- Экспорт CSV-отчёта по разделу 2.5 ТЗ.

## Требования

Windows 10/11 x64, macOS или Linux; Python 3.12+ x64. Минимальная конфигурация:
2 CPU, 2 ГБ RAM, 1 ГБ на диске; GPU не требуется. Типичное время обработки одного
изображения — меньше секунды. Готовая модель уже входит в поставку
(`models/dxa_qc_resnet18.pt`) — переобучение для проверки снимков не требуется.

## Локальный запуск

### Windows

1. Запустить `setup_windows.bat` и дождаться установки зависимостей (создаётся
   окружение `.venv`; при отсутствии `annotations/labels.csv` создаются первичные
   заготовки разметки).
2. Запустить `run_windows.bat`.
3. Открыть `http://localhost:1639`.

### macOS

Двойным щелчком по `run_mac.command`: при первом запуске он сам создаст окружение,
установит зависимости и откроет сервис. Если Terminal сообщает, что файл не выполняется,
один раз выполните из папки проекта `chmod +x run_mac.command scripts/*.sh` либо
запускайте через `sh run_mac.command`.

### Linux / macOS (терминал)

```bash
sh scripts/setup_unix.sh   # создать .venv и установить зависимости
sh scripts/run.sh          # запустить сервис
```

Открыть `http://localhost:1639` (остановка — Ctrl+C).

### Docker

```bash
docker compose up --build
```

Сервис поднимется на `http://localhost:1639`. Тестовый набор `Исследования_тест`
подключается read-only и показывается на сайте; обучающие данные в контейнер не
монтируются.

## Проверка снимков

На главном экране перетащите до 50 файлов DICOM, JPEG, PNG или WebP размером до 25 МБ
каждый — для каждого снимка вернутся отдельный результат: область, сторона, итоговое
решение (хороший/плохой), нарушенные критерии и статус решения. Загруженные файлы
не сохраняются. Интерактивная документация API — `http://localhost:1639/docs`.

## Переобучение и тесты

```powershell
.\scripts\train_windows.ps1 -Epochs 15      # повторное обучение (Windows)
```

```bash
sh scripts/run.sh                           # запуск (см. выше)
PYTHONPATH=src .venv/Scripts/python.exe -m pytest   # тесты (Windows)
PYTHONPATH=src .venv/bin/python -m pytest           # тесты (macOS/Linux)
```

Подробности: разметка, метрики, скрипты обучения и оценки — в
[DOCUMENTATION.md](DOCUMENTATION.md).

## Что где лежит

```
src/dxa_qc/            пакет сервиса (API, ML-пайплайн, веб-интерфейс)
scripts/               установка, запуск, обучение, оценка
tests/                 pytest-тесты
annotations/labels.csv экспертная разметка
models/                веса моделей, метрики, разбиение сплитов
Results/               обучающий набор: 80 исследований (207 снимков)
Исследования_тест/     внешний тестовый набор: 20 исследований (44 снимка)
output/                рабочие отчёты, логи обучения, презентация
```
